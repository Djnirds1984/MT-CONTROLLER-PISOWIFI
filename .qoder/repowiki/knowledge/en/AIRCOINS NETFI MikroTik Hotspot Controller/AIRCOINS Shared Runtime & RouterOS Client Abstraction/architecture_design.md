Flat collection of `require_once`-loaded PHP files with no autoloader or Composer dependency; dependency direction is one-way: `config.php` defines global constants; `db.php`, `crypto.php`, `helpers.php` depend only on config; `auth.php` depends on config + db; `csrf.php` depends on config + helpers + auth; `layout.php` depends on helpers + auth + csrf. The `RouterOS/` subdirectory isolates the MikroTik transport layer behind a single `RouterClientInterface` implemented by `RestClient` (HTTP Basic + JSON over `/rest`) and `LegacyApiClient` (binary sentence protocol over TCP/TLS port 8728/8729); `RouterFactory::aircoins_router_client()` selects the implementation based on the stored `api_type` field and decrypts `pass_enc` in memory via `crypto.php`. All files use `declare(strict_types=1)` and expose functions/classes in the global namespace so they can be required from any entry point without a PSR-4 loader.
