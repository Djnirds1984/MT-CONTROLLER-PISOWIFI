Flat collection of standalone PHP entry points under `admin/`, each a self-contained request handler that boots shared helpers via `require_once __DIR__ . '/../includes/*'` (db, auth, csrf, layout, crypto, RouterOS factory). Pages follow a POST-Redirect-GET flow: POST handlers call `csrf_verify()`, mutate state through `aircoins_router_client()` (REST or Legacy), then `header('Location: ...') exit;`. Read-only pages (`index.php`, `hotspot.php`) render HTML via `aircoins_header()` / `aircoins_footer()` from `includes/layout.php`; the login/logout endpoints are standalone (no chrome) and use `aircoins_session_start()` directly. Live metrics are decoupled into `api/monitor.php`, a JSON endpoint polled every 10s by `assets/admin.js` that diffs `rx-byte`/`tx-byte` counters against the `monitor_samples` table to compute per-interface rates. Authentication is session-based guarded by `aircoins_require_login()` on page scripts and an explicit session check + idle timeout in the monitor API. Router credentials are stored encrypted (`pass_enc` via `aircoins_encrypt`/`decrypt`) and never echoed back in forms.
