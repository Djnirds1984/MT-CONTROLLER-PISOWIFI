Four standalone HTML files (`login.html`, `alogin.html`, `logout.html`, `error.html`) are deployed onto the MikroTik router's `/hotspot/` directory so RouterOS serves them directly. Each file is a thin redirector: it uses `<meta http-equiv="refresh">` as the primary mechanism and a matching `location.replace()` JavaScript call as a fallback for browsers that ignore meta refresh. The pages consume RouterOS template variables (e.g. `$(mac-esc)`, `$(ip-esc)`, `$(link-redirect)`, `$(link-login-only-esc)`, `$(error-esc)`) which RouterOS substitutes before delivery; the `-esc` variants are used in query strings for proper URL encoding. `login.html` forwards to the SBC panel at `http://192.168.88.10/login.html` with full client context, `alogin.html` follows `$(link-redirect)` (typically the SBC status page), `logout.html` and `error.html` bounce back to the SBC login page carrying session/error parameters. `login.html` also carries the mandatory `<!-- IAMNOTLOGINSTRINGPLEASEDONTREMOVE -->` marker comment required by RouterOS to recognize it as the real login page.
