Two-host split documented in DEPLOYMENT.md: the MikroTik router serves only four RouterOS-substituted stubs (router_stubs/login.html, alogin.html, error.html, logout.html) that meta-refresh clients to the SBC's lighttpd server on port 80; the SBC runs hotspot_portal (pure HTML + JuanFi assets) plus /api/session.php for live MAC lookups, while the admin UI under admin_panel listens on port 443. All children share shared_includes for config, SQLite persistence, auth/CSRF/crypto helpers, and a unified RouterOS client abstraction (RestClient.php vs LegacyApiClient.php selected by RouterFactory.php). The deployment layer ships the RouterOS .rsc script that wires the hotspot profile, walled garden, IP binding, and services, and installs lighttpd/php-fpm with the aircoins.conf layout mapping portal/ to :80, app/admin/ to :443, and app/api/session.php via an aliased /api/ path. Client→SBC traffic uses HTTP-PAP over the isolated hotspot LAN; SBC→router management traffic goes exclusively over REST (v7, port 443) or Legacy binary API (v6/v7, ports 8728/8729), never SSH/screen-scraping.
